# 📄 Arabic CV Builder & Generator

تطبيق ويب تفاعلي وبسيط لبناء السير الذاتية الاحترافية باللغة العربية مع معاينة حية واقتراحات جاهزة وإمكانية التصدير كـ PDF.

## 🌟 الميزات
- دعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (RTL).
- اقتراحات عبارات جاهزة وملخصات مهنية بنقرة زر.
- نمطين للتصميم: عصري (Modern) وتنفيذي (Classic).
- إمكانية الطباعة والحفظ كـ PDF بتنسيق متوافق مع أنظمة الـ ATS.
- تجاوب كامل مع كافة الشاشات.

## 🛠️ التقنيات المستخدمة
- HTML5 / CSS3 / JavaScript (Vanilla)
- Bootstrap 5
- Google Fonts (Cairo)
