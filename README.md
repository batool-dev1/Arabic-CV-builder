A sleek, responsive, and user-friendly web application designed to help job seekers create, customize, and export professional Arabic resumes instantly with real-time rendering.

🌐 **Live Application:** [https://batool-dev1.github.io/Arabic-CV-builder/](https://batool-dev1.github.io/Arabic-CV-builder/)

---

## 🌟 Key Features

- **Dynamic Real-Time Rendering:** Instant live preview updates as users input personal details, work history, education, and skills.
- **Arabic Typography & RTL Native Support:** Custom layout optimized specifically for Right-to-Left (RTL) Arabic typography and structural alignment.
- **PDF Export & Print-Ready Formatting:** Seamless, one-click PDF export functionality configured for clean, single-page or multi-page output.
- **Modular Section Inputs:** Dedicated modules for managing work experience, academic background, technical competencies, and contact information.
- **Cross-Platform Responsiveness:** Fully responsive interface designed to perform smoothly across desktop, tablet, and mobile browsers.

---

## 🛠️ Architecture & Tech Stack

- **Frontend Core:** Semantic HTML5, Modular CSS3 Architecture, JavaScript (ES6+)
- **Styling:** Custom CSS Flexbox & Grid with native RTL positioning rules
- **Deployment & Hosting:** GitHub Pages Continuous Deployment
